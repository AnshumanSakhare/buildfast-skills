# README visual assets

The generated images in this repository were created with the built-in image-generation tool for this README revamp, then converted to WebP for fast GitHub rendering. They are editorial visuals, not screenshots of generated projects. Every consuming README labels them that way.

## Prompt set

```text

Asset type: repository README hero
Primary request: an original premium editorial collage that communicates five AI build capabilities: an ecommerce storefront, a landing page, a polished dashboard, a friendly realtime avatar, and a browser 3D game world
Scene/backdrop: deep charcoal studio canvas with subtle architectural grid and soft atmospheric depth
Subject: five distinct floating product-world vignettes arranged as one cohesive wide composition; recognizable interface-like forms but not literal screenshots
Style/medium: refined 3D editorial illustration with crisp product-design sensibility, glass and matte surfaces, restrained cinematic lighting
Composition/framing: 16:9 wide banner, strong central rhythm, generous clean margins, no cropping of key vignettes
Lighting/mood: confident, inventive, premium, controlled glow
Color palette: charcoal and warm ivory with selective electric cyan, violet, coral, and amber accents
Materials/textures: frosted glass, brushed metal, matte paper, soft emissive pixels
Constraints: no readable text, no letters, no logos, no trademarks, no watermark, no people, no code, no fake browser chrome
```

## Screenshot provenance

- Crazy Ecommerce Builder proof images were captured from the real STRATA example in [`buildfastwithai/crazy-ecommerce-builder`](https://github.com/buildfastwithai/crazy-ecommerce-builder), an MIT-licensed Build Fast with AI repository.
- Talking Avatar proof images were captured from the real Tsukiakari Books / Aiko example documented in [`buildfastwithai/talking-avatar`](https://github.com/buildfastwithai/talking-avatar), also MIT licensed.

The proof screenshots were converted from PNG to WebP without changing their content. All README assets together remain comfortably below 2 MB.
